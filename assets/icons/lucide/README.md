# Lucide toolbar icons

Source: https://github.com/lucide-icons/lucide/tree/3fef7aca71a50acc54bd2f24f0cc4747c22aa6d2/icons

Revision: 3fef7aca71a50acc54bd2f24f0cc4747c22aa6d2

SVG geometry is unchanged. The currentColor stroke is replaced with #ffffff so egui can tint icons for normal, selected and disabled states. The original 24 x 24 viewBox, 2-unit strokes and rounded caps/joins are retained.

Zoom menu icons: `maximize` for fit page, `move-horizontal` for fit width, and `square-equal` for actual size.

# 原生笔与 Direct 书写验收

日期：2026-11-09。对应 PLAN 步骤 5。

UI 更新：旧称 `Mouse pen` 对应齿轮设置的「鼠标书写」；`Smoothing` 对应路径模式的「简单 / 建模」，分别关闭 / 开启平滑。鼠标书写默认开启；底栏手掌切换为移动工具，鼠标和原生笔均拖动画布，不改变鼠标书写开关。默认黑色、最大笔宽 4.6 pt，色板和右侧笔宽可修改；压力曲线提供六种预设，每笔冻结样式。未保存计数在标题及 F12 状态栏显示；保存和另存为位于文档主菜单。最新 UI 操作见 [UI 手动验收](ui-validation.zh-CN.md)。

## 本次交付

- 直接依赖 crates.io 的 `tablet-input-windows = "=1.0.0"`，Cargo.lock 锁定发布包及校验和，无本地 path/vendor 依赖。
- 在 HWND 所在线程的 winit `with_msg_hook` 中同步读取原生笔与历史采样；仅把拥有所有权的采样延后交给应用。笔消息由此路径独占，过滤带 Windows 笔来源签名的鼠标消息。
- 画笔工具下，原生笔可在纸面书写；开启「鼠标书写」后左键以固定 0.5 压力书写，当前默认开启。移动工具下，原生笔和左键均用于平移，中键也可平移。步骤 6 已接入默认开启的「笔迹平滑」；关闭后继续使用本页验收的 Direct 路径，新增平滑专项见 [笔迹建模验收](modeling-validation.zh-CN.md)。
- Down 固定页面、原始页面方向、视图和 DPI；纸面之外开始的接触不会中途落墨。记录原始时间与设备属性，压力缺失和零压力分开保存，独立缺失的倾角轴不会丢失。Direct 不重采样，相同时间戳与重复点仍保留。
- 当前默认最大笔宽 4.6 pt，可在右侧调整；最小宽度比例 20%，压力指数 1.5。按采样增量追加圆头、圆角变宽轮廓；原始点和轮廓允许越界，显示时由原属纸面及画布共同裁剪。活动笔迹与已完成记录分开绘制，页面底图尚未到达也可显示笔迹。
- Cancel 丢弃整条活动笔迹。失焦、原生取消、捕获丢失、窗口尺寸或 DPI 变化，以及切换文档均结束当前活动输入；书写时暂停画布平移和缩放。工具栏视图操作取消当前未完成的一笔。
- 笔可操作工具栏和滚动条，UI 接触保持归属直到抬笔。橡皮端暂不落墨，侧键暂不触发编辑命令。
- 修饰键：Ctrl＋笔或鼠标左键上下拖动缩放（上放大、下缩小，以开始操作的位置为锚点），Alt＋拖动平移，同时按下时 Ctrl 优先。原生消息读取时同步记录 Ctrl/Alt/Shift 状态；UI 事件也使用该快照，避免上一帧状态滞后。历史采样使用所属消息的键盘状态。书写中按下 Ctrl/Alt 会在最后一个书写采样点终结并提交当前笔画，保留已有内容，再响应导航；导航点不接入原笔画，后续抬笔不重复提交。松键后本次接触暂停，抬笔重新开始才恢复书写。

**当前新增笔迹已可通过 Ctrl+S 或另存为保存，验收见 [正式保存手动验收](saving-validation.zh-CN.md)。** 步骤 7 已接入撤销重做、修订状态和未保存确认，详见 [编辑状态手动验收](editing-validation.zh-CN.md)。恢复日志仍待后续步骤。

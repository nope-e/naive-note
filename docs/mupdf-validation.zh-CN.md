# MuPDF 第一页预览验收

2026-11-06 接入 `mupdf 0.8.0` / MuPDF 1.27.2。范围为第一页只读预览；不包含多页连续阅读、手写、编辑和保存。所有窗口、视觉与实际输入项目由用户手动执行；Agent 不启动窗口、不操作 GUI、不截图或回读窗口帧缓冲。

## 无窗口检查

`LIBCLANG_PATH` 应指向 `libclang.dll` 所在目录，具体环境准备见 [README](../README.md)。

```powershell
cargo fmt --all -- --check
cargo check --offline --locked --all-targets
cargo clippy --offline --locked --all-targets -- -D warnings
cargo test --offline --locked
cargo build --offline --locked
```

PDF 测试在内存中构造 PDF，验证解析、页数、有效 CropBox、继承属性、旋转、UserUnit、坐标映射及 CPU 位图尺寸/缓冲区结构。中文路径与文件释放测试在项目 `.scratch` 内操作文件。测试不创建窗口、不导出页面图片、不检查像素内容，不能证明字体或实际画面正确。

2026-11-06：MSVC 离线锁定构建、格式检查、Clippy 全目标零警告检查通过；`cargo test --offline --locked` 的 16 项测试全部通过（10 项坐标测试，6 项 PDF/worker 测试），包括待处理任务替换、关闭后失效及重新打开。验证时显式配置本机 libclang，并通过 `SKIA_BINARIES_URL` 复用项目内同版本的 Skia 预编译缓存；其 SHA256 为 `630de78b5ba4c496588729e6371db2453008be01ef6f7711235898c97fe7f890`。这属于缓存准备后的离线检查，未验证干净机器首次构建或发行包。

## 用户手动步骤

由用户运行 `cargo run --locked`，也可用 `cargo run --locked -- 'D:\documents\中文示例.pdf'` 直接打开文件。

| 项目 | 操作 | 预期结果 |
| --- | --- | --- |
| 打开 | 点击 Open PDF 或按 Ctrl+O 选择普通 PDF | 显示加载状态，随后第一页适合画布；底栏显示实际页数和只读状态 |
| 中文路径与内容 | 从中文目录打开中文 PDF，嵌入字体与缺失字体样本分别检查 | 路径可打开；与其他阅读器核对文字和符号；系统字体回退效果单独记录 |
| 扫描与复杂内容 | 打开扫描页、透明图片、渐变、向量或已有批注的样本 | 方向、颜色、裁剪和既有批注与其他阅读器一致 |
| 页面几何 | 打开偏移 CropBox、90/180/270 度旋转、非 1 UserUnit 的 PDF，按 F12 查看信息 | 比例和方向正确，坐标对应有效 CropBox，旋转不被重复应用 |
| 视图交互 | 缩放、拖动、Fit page、100%、连续旋转四次 | 鼠标锚点缩放和原画布一致；画面受中央区域裁剪；四次旋转回到原方向；源文件不改写 |
| 布局与 DPI | 工具栏操作、调整窗口、最小化恢复、100/150/200% DPI 或跨屏 | 工具栏不移动纸面；画布位置和裁剪正确；恢复后页面可见 |
| 替换与取消 | 加载 A 后打开对话框再取消；快速拖入 A/B | 取消保留当前页；最终只显示最新请求的结果，旧结果不覆盖新文档 |
| 关闭与取消加载 | 加载中或完成后按 Ctrl+W | 返回网格测试页；旧结果不重新出现；正在光栅化的调用先收尾再释放 |
| 错误 | 打开损坏、无页面、需要密码或超过 256 MiB 的文件 | 显示错误，悬停可读完整消息；保留已加载页面，可继续打开其他文件 |
| 源文件释放 | 打开后从资源管理器重命名或移动源文件 | 预览仍可显示，内存快照不锁住源文件 |
| 响应与退出 | 加载时操作视图，完成后等待，再关闭窗口 | 读取和 PDF 渲染在后台；结果到达重绘；退出释放 worker，渲染中可能等待收尾 |

预览限制：仅第一页，最高 144 DPI，最长边 2048 px；大幅放大暂不补高清。表中项目全部待用户验收，编译或结构测试通过不代表视觉验收通过。

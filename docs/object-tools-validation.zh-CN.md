用户运行 `cargo run --offline --locked`，准备可丢弃的新草稿和带第三方批注的多页 PDF。分别用鼠标和原生笔重复，建议覆盖 100% / 150% / 200% DPI、缩放和页面旋转。

荧光笔为自由手写对象，保存为标准 `/Ink` 批注和带透明叠色的自定义 `/AP`，附带可编辑数据；不属于基于 PDF 文字范围的 `/Highlight` 标注。本轮选择支持点选、矩形框选和清除，不包含移动、缩放或套索。

非窗口验证覆盖命中几何、压感粗细、稀疏擦除路径、停留轮廓合并、输入归属、取消、批量撤销及原对象顺序、保存重开后的对象替换、附件和透明度资源校验；不启动窗口、不操作 GUI、不截图或回读窗口帧缓冲。

实现记录：荧光笔已去掉固定宽度限制，按采样压力及该笔冻结的压力曲线生成粗细。停留时不再为每个采样累积重复端点轮廓；新圆覆盖旧圆时替换端点，旧圆已覆盖新圆时省略冗余几何，并合并小幅模型抖动。连接以最后绘制的端点为锚，抬笔补齐末端；完整采样仍进入编辑附件。确认轮廓与预测尾段一次填充，保持单笔连接处的透明度一致。

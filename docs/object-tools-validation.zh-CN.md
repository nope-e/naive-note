# 对象工具与荧光笔手动验收

2026-11-10：对象橡皮擦、对象选择与清除、压感荧光笔已接入。用户在荧光笔压感和笔尖停留断续问题修复后反馈“没问题了”，当前效果已获总体手动确认。未提供设备型号、DPI、停留时长或逐项结果，以下清单继续用于专项回归记录；总体反馈及自动检查均不代表整张清单已通过。

同日新增套索选择、选区移动和自由旋转，并扩展了跨页移动。此部分仅完成非窗口检查，以下新增交互、视觉及跨阅读器项目均待用户手动验收。

用户运行 `cargo run --offline --locked`，准备可丢弃的新草稿和带第三方批注的多页 PDF。分别用鼠标和原生笔重复，建议覆盖 100% / 150% / 200% DPI、缩放和页面旋转。

荧光笔为自由手写对象，保存为标准 `/Ink` 批注和带透明叠色的自定义 `/AP`，附带原始输入数据；不属于基于 PDF 文字范围的 `/Highlight` 标注。选择支持点选、矩形框选、套索、跨页移动、旋转和清除，适用于本应用墨迹及可解析的标准批注，不含对象缩放。标准批注使用边界进行对象命中和区域包围判断；链接、表单控件和附属弹注不作为独立对象，无法解析或采用直接对象存储的批注保留在底图。套索从空白处开始；已有选区内拖动用于移动，按 Shift 可在原选区内开始追加圈选。移动不自动滚动视图，可先调整倍率和位置，让目标页可见；整组归属以松手所在页为准。本应用墨迹变换保留原始采样；标准批注直接变换当前标准坐标与 AP，不依赖原始采样或附件校验。

非窗口验证覆盖凹形套索和完整压感轮廓包围、闭合及追加选择、命中几何、压感粗细、稀疏擦除路径、停留轮廓合并、输入归属、取消、批量变换和撤销、原始采样及对象顺序、页面 / 视图旋转与 DPI 坐标映射、保存重开后的对象替换、附件和透明度资源校验；不启动窗口、不操作 GUI、不截图或回读窗口帧缓冲。

实现记录：荧光笔已去掉固定宽度限制，按采样压力及该笔冻结的压力曲线生成粗细。停留时不再为每个采样累积重复端点轮廓；新圆覆盖旧圆时替换端点，旧圆已覆盖新圆时省略冗余几何，并合并小幅模型抖动。连接以最后绘制的端点为锚，抬笔补齐末端；完整采样仍进入编辑附件。确认轮廓与预测尾段一次填充，保持单笔连接处的透明度一致。

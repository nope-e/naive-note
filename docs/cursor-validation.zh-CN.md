# 画布指针手动验收

参照本地 Rnote 的 `crates/rnote-ui/src/canvas/mod.rs`、`canvas/input.rs` 和 `settingspanel/mod.rs`，区分悬停、书写两套指针，默认分别为中圆点、小圆点，允许隐藏书写指针。提供圆点、十字、光标线、三个方向的水滴及系统箭头；自定义样式有小、中、大三档。图像由本项目生成，通过 egui-winit 的原生自定义指针接口显示，按 DPI 缓存，不随文档缩放改变大小。橡皮擦原有画布圆圈改为半径 8 逻辑像素的原生指针，避免双重指示及重绘延迟。

所有窗口、视觉和真实设备行为仍待用户手动验收。Agent 只运行编译、静态检查、纯输入状态和设置读写测试，不启动应用窗口，不做截图或窗口帧缓冲回读。

用户运行 `cargo run --offline --locked`，新建可丢弃草稿：

| 操作 | 预期结果 |
| --- | --- |
| 选择画笔或荧光笔，移动鼠标、按住左键书写、抬起 | 悬停中号红色实心圆点，实际书写时小号红色实心圆点，带白色描边，抬起恢复；指针热点与墨迹位置重合 |
| 右上角设置 → 全局设置 → 鼠标指针，分别改变悬停及书写样式、大小 | 两套设置独立生效；三个方向的水滴以尖端落笔；设置面板继续打开 |
| 关闭「显示书写指针」，书写后抬起；写到一半按 Esc、切工具或切出窗口再返回 | 只有实际书写期间隐藏指针；结束或取消后恢复，无指针残留隐藏 |
| 选择移动工具拖动；在其他工具下按 Alt / Ctrl 拖动；用中键拖动 | 移动时张手，拖动时握手；Ctrl 显示放大镜并缩放；不受「显示书写指针」开关影响 |
| 关闭鼠标书写后移动及拖动，再重新开启 | 关闭时鼠标显示抓手、拖动画布；开启后画笔和荧光笔恢复书写指针 |
| 切对象橡皮擦、选择工具，悬停及拖动 | 橡皮擦显示单个圆圈，擦除范围与圆圈一致；选择工具显示十字；不会同时出现旧画布圆圈 |
| 从画布移到工具栏、设置、滚动条、弹出菜单、窗口边缘；打开新建或退出确认界面 | 自定义画布指针退出，控件、文本框和窗口边缘使用各自指针；不将画布的隐藏状态带入 UI |
| 在 100% / 150% / 200% DPI 或不同 DPI 屏幕间移动窗口，改变文档缩放 | 指针清晰、大小随 DPI 调整；文档缩放不改变其屏幕大小；热点不偏移 |
| 用原生笔悬停、书写、抬笔、移出感应范围；用笔尾悬停、擦除；用笔操作设置 | 书写和 UI 输入归属保持；悬停、落笔正确切换；笔尾临时显示擦除圆圈，移动工具及 Ctrl / Alt 优先 |
| 调整两套指针设置并重启应用；已有旧版设置时首次启动 | 设置保留；旧设置自动补齐默认指针，原颜色、笔宽等设置保留 |

非窗口测试覆盖鼠标/笔落笔与抬笔的样式切换、隐藏后的恢复、导航与对象工具优先级、笔悬停及笔尾切换、取消及 UI 接触、旧设置兼容和读写回验。测试通过不代表上述外观、窗口或设备行为已经通过。

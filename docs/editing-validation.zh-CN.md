# 编辑命令与文档状态手动验收

日期：2026-11-10，对应 PLAN 步骤 7。实现已接入，以下窗口、视觉及真实输入项目均待用户手动验收。Agent 不启动窗口、不操作 GUI、不截图、不回读窗口帧缓冲。

由用户运行 `cargo run --offline --locked`，准备一份多页 PDF（最好带已有批注），使用可丢弃的会话笔迹。Ctrl+S、另存为及确认框保存已在步骤 8 接入，详见 [正式保存手动验收](saving-validation.zh-CN.md)；恢复日志尚未接入。模拟笔迹测试导出不会保存真实书写内容。

## 操作与预期

| 操作 | 预期结果 |
| --- | --- |
| 在空草稿中依次写 A、B、C；用底栏和主菜单撤销，再用 Ctrl+Z 重复 | 每次撤销最后提交的一笔；标题会话笔数递减；撤销到零后不再显示未保存更改，撤销按钮禁用，重做可用 |
| 用 Ctrl+Y、Ctrl+Shift+Z、底栏和菜单分别重做 | 每次恢复一笔，顺序、位置、颜色、宽度及平滑结果保持原样；全部恢复后重做禁用；未保存状态恢复 |
| 撤销 C，改写 D，再尝试重做 | C 的重做分支消失；D 可以独立撤销 / 重做。F12 当前修订号不复用 C 的旧编号，未保存状态正确 |
| 打开带已有批注的多页 PDF，先检查撤销状态；在第 1、2、1 页依次新增三笔，再撤销 / 重做 | 打开时历史为空；撤销只影响本次会话的三笔，按全局时间顺序跨页处理；PDF 原有内容和批注不变，底图补图后不重复叠加 |
| 修改颜色、笔宽、压力曲线和简单 / 建模模式后再书写；撤销并重做旧笔迹 | 新设置影响下一笔，旧笔迹及其重做结果保持原样；修改设置本身不计作文档编辑 |
| 编辑页码、笔宽、倍率或十六进制颜色时按 Ctrl+Z / Ctrl+Y | 文本输入框处理自身编辑，不撤销 / 重做画布笔迹；退出文本编辑后快捷键恢复会话编辑 |
| 有未保存笔迹时 Ctrl+O，先取消文件选择；再选择另一 PDF，分别取消确认、按 Esc 或点击确认框外部 | 取消文件选择保持原文档，不出现丢弃确认；选择路径后才确认。三种取消方式均保留原笔迹、修订和撤销 / 重做分支 |
| 有未保存笔迹时拖入另一 PDF，先取消再重试并丢弃 | 取消不切换文档；丢弃后加载目标，成功时新会话无未保存状态且撤销 / 重做禁用 |
| 撤销一笔以保留重做分支，选择无效 PDF 并确认丢弃 | 打开失败显示错误；原文档、已有会话笔迹及重做分支仍保留。打开成功后才会重置历史 |
| 有未保存内容时用 Ctrl+W / 菜单关闭草稿或 PDF，分别取消和丢弃 | 取消保留文档与历史；丢弃后回到空草稿、100% 初始视图，历史清空。草稿已有编辑或重做历史时也可以关闭 |
| 有未保存内容时分别点击标题栏关闭、按 Alt+F4，再取消；最后重试并丢弃 | 两种入口都提示未保存；取消保留窗口和历史，丢弃才退出；也可保存成功后退出 |
| 已写一笔，再写到一半请求打开 / 关闭 / 退出；取消确认后重新落笔 | 未完成的一笔及预测尾段被取消；已完成的笔迹保留，历史不变；后续重新落笔不连接旧笔迹 |
| 确认框打开期间在纸面用鼠标或笔点按、Ctrl / Alt 拖动，重复按关闭或拖入其他文件 | 不新增笔迹，不移动视图，不替换当前等待确认的操作；笔可以点击确认框的按钮，点击不穿透纸面 |
| 选择目标并确认丢弃，在后台尚未打开完成时关闭文档 | 直接取消已授权的加载，回到空草稿；迟到结果不重新打开旧文件 |
| 撤销全部会话笔迹后关闭 / 打开 / 退出 | 当前已回到初始内容，不再提示未保存；新文档不继承重做历史 |

## 非窗口验证的范围

`cargo test --offline --locked` 检查命令顺序、同一笔迹对象的恢复、分支修订与保存检查点、重复提交、文档替换成功 / 失败 / 过期结果，以及取消 / 丢弃的纯状态路由。测试不创建 event loop，不运行 egui 布局、GL 或原生对话框。步骤 8 已补充真实文件保存和延迟修订检查点测试；实际窗口中的保存后撤销、保存期间继续编辑及重开外观仍需用户验收。

格式、Clippy、编译与这些测试通过不代表上表已验收。请记录草稿 / PDF、鼠标 / 原生笔、系统 DPI 和失败步骤。

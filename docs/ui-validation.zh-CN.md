# 工作区 UI 手动验收

本轮先实现参考图的 UI，复用现有书写和 PDF 阅读能力。所有视觉、窗口、真实鼠标和笔操作均由用户执行；Agent 不启动窗口、不操作 GUI、不截图或回读帧缓冲。

## 启动

正常构建后由用户运行 `cargo run --offline --locked`。旧版 `naive-note-ui.exe` 属于先前 UI 验证构建，步骤 7 的最新行为请使用本次构建的 `naive-note.exe`。

## 操作与预期

| 操作 | 预期结果 |
| --- | --- |
| 启动并观察整体布局 | 深灰工作区，居中「新建文档 / 草稿」标题；顶部浮动色板、右侧笔宽栏、底部工具栏；白纸为浅蓝方格，没有旧测试圆形及四色角标；草稿初始 100%，可向下滚动；左下角始终显示倍率和页码 |
| 检查各处设置入口，再在较窄窗口下检查标题栏 | 顶部色板只负责颜色，底栏提供工具和会话撤销重做；画笔设置仅在右侧齿轮，缩放预设仅在左下角倍率弹窗；打开、保存和导出等文档操作仅在主菜单；标题栏菜单与窗口按钮紧凑排列，不遮挡居中标题 |
| 切换色板，打开拾色面板选择色阶，分别取消和确认，再调整右侧笔宽；分别用鼠标及原生笔写字 | 取消不修改当前颜色，确认后新笔画使用所选颜色；自定义可输入十六进制颜色；粗细可调整，历史笔迹保持样式，标题显示未保存笔数 |
| 点底栏手掌，用鼠标和原生笔分别拖动，再点画笔书写；在齿轮中切换「鼠标书写」和路径模式「简单 / 建模」 | 手掌下左键和原生笔均平移且不落墨，画笔下恢复书写；鼠标书写开关只影响画笔模式的鼠标，不改变工具或原生笔行为；简单关闭平滑、建模开启平滑，从下一笔生效；曲线保留禁用占位 |
| 从右侧齿轮打开设置，分别点击压力曲线行的文字、当前值和箭头；依次选择六项，再用原生笔改变压力书写 | 设置在齿轮左侧留有间距；压力曲线整行可打开选项，选择后仅收起曲线菜单，设置面板保留且显示新值；再次点击仍可选择；固定值始终采用最大笔宽，其余五项产生不同粗细响应；当前笔画和历史笔迹保持原样 |
| 草稿与多页 PDF 中，使用左下角缩小 / 放大、倍率菜单、页码输入和翻页 | 单页也显示倍率及 1 / 1；多页可跳页；适合整页、适合宽度、实际大小、旋转和自定义倍率可用；在倍率弹窗内操作后保持打开，可连续调整，点击外部或按 Esc 关闭；专注模式仍保留此栏 |
| 用笔 / 鼠标点色板、笔宽、底栏和菜单；从这些控件按下后拖到纸上；打开菜单后在纸面点击关闭菜单 | 控件可操作且不会落墨；UI 开始的拖动不变成书写或画布导航；点击关闭菜单不额外产生笔迹 |
| 检查荧光笔、文本、橡皮擦、选区和通用导出；写字后检查撤销 / 重做 | 前五项显示禁用占位；保存和另存为按任务状态启用；撤销 / 重做按会话历史启用，支持 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z |
| Ctrl+O 打开多页 PDF；展开左上页面列表、使用左下角导航 | 标题改为文件名，PDF 从第一页适合整页；页码、列表、缩放和旋转可用，底图与笔迹仍按原页面裁剪 |
| 打开无效 PDF，关闭错误提示 | 可见错误提示，悬停能看完整信息；旧文档仍可显示；关闭提示后回到工作区 |
| 切换左上专注模式与 F12 | 专注模式收起浮动工具和页面列表，可再次点击退出；F12 展开原有渲染、坐标和帧率信息 |
| 拖动标题栏、双击标题栏、点最小化 / 最大化 / 还原；拖四边四角调整尺寸 | 原生窗口响应相应操作；恢复后可继续书写；窄于 1120 逻辑像素时底部工具栏上移一行，左下角导航保持原位；在最小 640×480 和较大窗口下检查布局与弹出面板 |
| 在 100%、150%、200% DPI 下及跨屏后重复布局和输入操作，最后点击关闭 | 图标文字清晰、布局可用、笔和鼠标坐标一致，窗口正常退出 |

步骤 7 已接入撤销重做和未保存确认，详见 [编辑状态手动验收](editing-validation.zh-CN.md)。步骤 8 已支持 Ctrl+S、另存为及关闭前保存，见 [正式保存手动验收](saving-validation.zh-CN.md)。恢复日志、文本、橡皮擦等仍未接入。

## 验证边界

编译、格式、Clippy 和纯数据单元测试不代表上述项目通过。新测试覆盖浮动 UI 的输入归属标记、笔画样式快照、当前工具对笔和鼠标的路由，以及草稿初始视图的坐标策略，不运行 egui 布局或窗口。

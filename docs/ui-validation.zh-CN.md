# 工作区 UI 手动验收

本轮先实现参考图的 UI，复用现有书写和 PDF 阅读能力。所有视觉、窗口、真实鼠标和笔操作均由用户执行；Agent 不启动窗口、不操作 GUI、不截图或回读帧缓冲。

## 启动

正常构建后由用户运行 `cargo run --offline --locked`。旧版 `naive-note-ui.exe` 属于先前 UI 验证构建，步骤 7 的最新行为请使用本次构建的 `naive-note.exe`。

## 当前取色面板

画笔、全局参考线与文档参考线共用同一个拾色组件。上方为 9 × 5 预定义色阶及最近确认颜色，下方直接显示 egui 自定义取色区域、色相条、RGB 和 HEX。内容宽度为 280 逻辑像素，缩紧色块、按钮与间距；短窗口下滚动内容，底部保留选择 / 取消。HEX 输入宽度为 110 逻辑像素，显式使用正文样式（当前 13 号字）。

最近颜色只记录本次运行中各拾色器最近确认的至多 7 色，不持久化。画笔与参考线分别维护最近颜色，全局 / 文档参考线共用参考线拾色器。预设与自定义操作先修改待确认颜色；点击「选择」后应用，取消、关闭、外部点击或 Esc 放弃待确认修改，重新打开从目标当前颜色开始。

中文和复制图标分别使用 Windows `msyh.ttc`、`seguisym.ttf` 作为比例与等宽字体的回退，字体路径为 `%WINDIR%/Fonts/`，未设置 `WINDIR` 时使用 `C:\Windows/Fonts/`；文件缺失时记录警告，继续使用其余可用字体。复制按钮沿用 egui 的字符 `📋`。

## 操作与预期

| 操作 | 预期结果 |
| --- | --- |
| 启动并观察整体布局 | 深灰工作区，居中「新建文档 / 草稿」标题；顶部浮动色板、右侧笔宽栏、底部工具栏；白纸为浅蓝方格，没有旧测试圆形及四色角标；草稿初始 100%，可向下滚动；左下角始终显示倍率和页码 |
| 检查各处设置入口，再在较窄窗口下检查标题栏 | 顶部色板只负责颜色，底栏提供工具和会话撤销重做；画笔设置仅在右侧笔宽栏齿轮；标题栏齿轮打开全局 / 文档设置侧栏，自动保存间隔位于全局页签；缩放预设仅在左下角倍率弹窗；打开、保存和导出等文档操作仅在主菜单；标题栏齿轮、菜单与窗口按钮紧凑排列，不遮挡居中标题 |
| 切换色板，打开拾色面板选择色阶，再拖动下方自定义取色区域、色相条，编辑 RGB 和 HEX；分别取消和确认，再调整右侧笔宽并书写 | 上方为预定义色阶及已确认的最近颜色，下方直接显示自定义取色器；色阶、取色区域、RGB 和 HEX 同步；不完整或无效 HEX 提示错误并禁用确认；取消、点外部或 Esc 不修改当前颜色，确认后新笔画使用所选颜色，历史笔迹保持样式 |
| 在全局设置与当前文档设置中分别打开「纹理颜色」，选色后取消或确认；交替打开画笔拾色面板 | 三处使用同一拾色面板布局和确认方式；确认只修改对应目标，取消后重开恢复该目标当前颜色；小窗口可滚动查看色阶和自定义取色器，底部选择／取消按钮保持可用 |
| 在小窗口和不同 DPI 下打开拾色器，编辑 HEX | 面板保持紧凑，色块与按钮可用；HEX 输入宽度保持 110 逻辑像素，字高与周围正文协调，没有明显缩小或裁切 |
| 检查取色器 U8 / F 后的复制按钮，点击后粘贴到文本编辑器 | 显示剪贴板图标，不出现缺字方框；复制内容与当前 RGB 数值一致 |
| 点底栏手掌，用鼠标和原生笔分别拖动，再点画笔书写；在齿轮中切换「鼠标书写」和路径模式「简单 / 建模」 | 手掌下左键和原生笔均平移且不落墨，画笔下恢复书写；鼠标书写开关只影响画笔模式的鼠标，不改变工具或原生笔行为；简单关闭平滑、建模开启平滑，从下一笔生效；曲线保留禁用占位 |
| 从右侧齿轮打开设置，分别点击压力曲线行的文字、当前值和箭头；依次选择六项，再用原生笔改变压力书写 | 设置在齿轮左侧留有间距；压力曲线整行可打开选项，选择后仅收起曲线菜单，设置面板保留且显示新值；再次点击仍可选择；固定值始终采用最大笔宽，其余五项产生不同粗细响应；当前笔画和历史笔迹保持原样 |
| 草稿与多页 PDF 中，使用左下角缩小 / 放大、倍率菜单、页码输入和翻页 | 单页也显示倍率及 1 / 1；多页可跳页；适合整页、适合宽度、实际大小、旋转和自定义倍率可用；在倍率弹窗内操作后保持打开，可连续调整，点击外部或按 Esc 关闭；专注模式仍保留此栏 |
| 用笔 / 鼠标点色板、笔宽、底栏和菜单；从这些控件按下后拖到纸上；打开菜单后在纸面点击关闭菜单 | 控件可操作且不会落墨；UI 开始的拖动不变成书写或画布导航；点击关闭菜单不额外产生笔迹 |
| 检查荧光笔、文本、橡皮擦、选区和通用导出；写字后检查撤销 / 重做 | 前五项显示禁用占位；保存和另存为按任务状态启用；撤销 / 重做按会话历史启用，支持 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z |
| Ctrl+O 打开多页 PDF；展开左上页面列表、使用左下角导航 | 标题改为文件名，PDF 从第一页适合整页；页码、列表、缩放和旋转可用，底图与笔迹仍按原页面裁剪 |
| 设置全局参考线为点阵，打开没有参考线配置的 PDF，再调整全局样式；随后新建文档 | PDF 从首屏起不显示参考线，调整全局样式也不影响它；新建文档采用当前全局参考线样式 |
| 在打开的 PDF 的「当前文档」页签中启用参考线，保存后重开，再修改全局样式 | 保存重开后恢复文档自己的参考线配置，不受全局修改影响；文档纹理设为「无」并保存后重开仍不显示参考线 |
| 打开无效 PDF，关闭错误提示 | 可见错误提示，悬停能看完整信息；旧文档仍可显示；关闭提示后回到工作区 |
| 切换左上专注模式与 F12 | 专注模式收起浮动工具和页面列表，可再次点击退出；F12 展开原有渲染、坐标和帧率信息 |
| 拖动标题栏、双击标题栏、点最小化 / 最大化 / 还原；拖四边四角调整尺寸 | 原生窗口响应相应操作；恢复后可继续书写；窄于 1120 逻辑像素时底部工具栏上移一行，左下角导航保持原位；在最小 640×480 和较大窗口下检查布局与弹出面板 |
| 在 100%、150%、200% DPI 下及跨屏后重复布局和输入操作，最后点击关闭 | 图标文字清晰、布局可用、笔和鼠标坐标一致，窗口正常退出 |

步骤 7 已接入撤销重做和未保存确认，详见 [编辑状态手动验收](editing-validation.zh-CN.md)。步骤 8 已支持 Ctrl+S、另存为及关闭前保存，见 [正式保存手动验收](saving-validation.zh-CN.md)。定时自动保存及草稿恢复已接入，标题栏齿轮 → 全局设置 → 自动保存的检查间隔支持左右加减按钮（每次 1 秒，范围 5–15 秒），详见 [自动保存验收](autosave-validation.zh-CN.md)；文本和橡皮擦仍未接入。

## 验证边界

统一拾色面板、紧凑尺寸及 HEX 字号已有静态检查记录；新增符号字体回退的完整构建 / 静态检查结果尚未确认。字体文件包含对应字符的静态检查不能证明实际图标显示或复制行为通过，本页窗口与交互项目仍待用户验收。

编译、格式、Clippy 和纯数据单元测试不代表上述项目通过。新测试覆盖浮动 UI 的输入归属标记、笔画样式快照、当前工具对笔和鼠标的路由，以及草稿初始视图的坐标策略，不运行 egui 布局或窗口。

# 画布区域与坐标基础验收

步骤 1 的代码已接入。本文的视觉、窗口和实际输入项目均待用户手动执行；Agent 不启动窗口、不操作 GUI、不截图，也不执行帧缓冲回读。

## 非窗口检查

```powershell
cargo fmt --all -- --check
cargo check --offline --locked --all-targets
cargo clippy --offline --locked --all-targets -- -D warnings
cargo test --offline --locked document::
cargo test --offline --locked app::frame_scheduler::
cargo build --offline --locked --target x86_64-pc-windows-msvc
```

`document::` 测试仅执行坐标数学，不创建窗口。覆盖四种旋转、正负 CropBox 偏移、非整数 UserUnit、纸面边界、非法参数、100% 缩放的基准换算、鼠标缩放锚点及上下限、适合页面、平移、布局变化、DPI 换算和完整坐标链往返。

`app::frame_scheduler::` 测试仅验证时间和调度状态，不创建窗口、不等待真实帧间隔。覆盖 60 FPS 上限、密集重绘请求合并、提前收到的系统重绘、egui 延迟期限、慢帧不追帧，以及隐藏和恢复后的期限。

2026-11-06 已通过格式检查、Clippy 全目标零警告检查、MSVC 离线锁定构建和 10 个坐标数学测试。以下视觉、窗口与实际输入项目仍待用户验收。

## 坐标约定

| 坐标 | 原点与单位 |
| --- | --- |
| PDF 用户空间 | x 向右、y 向上；保留 CropBox 的原始偏移；每单位为 UserUnit / 72 英寸 |
| 归一化纸面 | 已应用 CropBox、UserUnit 和顺时针旋转；左上角为原点，y 向下；单位为 1/72 英寸的 point |
| 客户区逻辑坐标 | 原点为整个窗口客户区左上角；中央画布有独立的矩形边界；纸面通过视图平移和缩放映射到此坐标 |
| 客户区物理像素 | 逻辑坐标乘 egui 的 pixels_per_point；中央区域的整数物理边界向外取整并限制在帧缓冲内 |

100% 缩放采用 `1 纸面 point = 96/72 逻辑像素`。DPI 比例单独应用。Skia 裁剪使用精确的逻辑边界映射到物理像素，不用取整边界代替布局边界。

当前草稿纸的 CropBox 为 `[20, 30, 615, 872]`，UserUnit 为 1。未旋转时大小为 595×842 pt；网格间距 18 pt，统一浅蓝色，左上角有绿色原点十字。新 UI 已移除旧四色角标和中心圆形，草稿默认 100% 而非 fit。诊断状态栏通过 F12 展开，适合页面 / 旋转等选项已移到左下角倍率菜单；鼠标默认书写，平移前选择底栏手掌。参见 [UI 手动验收](ui-validation.zh-CN.md)。


| 滚动与平移 | 在中央区滚动；Shift＋滚轮；分别用左键和中键拖动 | 纸面分别纵向、横向或随拖动移动；拖动离开中央区后仍属于原来的画布手势，松开后结束 |

| 缩放按钮与复位 | 使用 - / +、100% / Ctrl＋1、Fit page / Ctrl＋0 | 按钮缩放保持画布中心锚点；100% 显示为 100%；Fit 恢复居中和整页显示，极小画布仍受最小缩放限制 |

| F12 帧率上限 | 按 F12，等待一秒后连续缩放、平移；最小化几秒后恢复；再次按 F12 隐藏；有高刷屏时一并测试 | 信息栏显示 `FPS: -- / 60 max`，约半秒后显示持续更新的一位小数帧率，最高约 60；性能或屏幕刷新率较低时可以低于 60；恢复后重新采样；隐藏后恢复按需重绘 |

### 定位标记坐标核对

先在未旋转草稿纸左上方第二个网格交点写一个点，按 F12 核对 Paper 约为 `(36, 36)`。该点在 PDF 用户空间始终为 `(56, 836)`；旋转后将鼠标移到笔迹附近，F12 状态栏的 PDF 坐标应接近该值，对应 Paper 坐标如下。

| 顺时针旋转 | 自绘定位点的 Paper 坐标（pt） |
| --- | --- |
| 0° | (36, 36) |
| 90° | (806, 36) |
| 180° | (559, 806) |
| 270° | (36, 559) |

旋转会改变纸面坐标；缩放和平移只改变显示位置。验收时可记录通过的项目、DPI 以及未通过项目的复现步骤，再更新 PLAN.md 的状态。

## 坐标约定

| 坐标 | 原点与单位 |
| --- | --- |
| PDF 用户空间 | x 向右、y 向上；保留 CropBox 的原始偏移；每单位为 UserUnit / 72 英寸 |
| 归一化纸面 | 已应用 CropBox、UserUnit 和顺时针旋转；左上角为原点，y 向下；单位为 1/72 英寸的 point |
| 客户区逻辑坐标 | 原点为整个窗口客户区左上角；中央画布有独立的矩形边界；纸面通过视图平移和缩放映射到此坐标 |
| 客户区物理像素 | 逻辑坐标乘 egui 的 pixels_per_point；中央区域的整数物理边界向外取整并限制在帧缓冲内 |

100% 缩放采用 `1 纸面 point = 96/72 逻辑像素`。DPI 比例单独应用。Skia 裁剪使用精确的逻辑边界映射到物理像素，不用取整边界代替布局边界。

当前测试页的 CropBox 为 `[20, 30, 615, 872]`，UserUnit 为 1。未旋转时大小为 595×842 pt；网格间距 18 pt，72 pt 网格线加深。原始方向的四角标记分别为左上红圆点、右上绿方框、左下蓝十字、右下橙菱形，中心为青绿色圆形。

## 手动步骤与预期结果

由用户运行：

```powershell
cargo run --offline --locked
```

| 待验收项目 | 操作 | 预期结果 |
| --- | --- | --- |
| 首次显示与布局 | 启动，观察工具栏、底部状态栏和中央纸面 | 灰色工作区内有完整白纸、网格、四色角标和圆形；纸面在可用区域居中；状态为 fit |
| 鼠标位置缩放 | 将鼠标放在一个网格交点，按住 Ctrl 连续滚动 | 交点保持在鼠标下方；状态栏的 Paper 坐标基本不变；缩放在 10%—800% 范围内；工具栏和状态栏保持大小 |
| 滚动与平移 | 在中央区滚动；Shift＋滚轮；分别用左键和中键拖动 | 纸面分别纵向、横向或随拖动移动；拖动离开中央区后仍属于原来的画布手势，松开后结束 |
| 输入归属 | 在工具栏或状态栏滚动；从工具栏开始拖动后移入画布；在工具栏滚动后立即移入画布 | 纸面不因这些操作移动或缩放；来自控件区的滚轮平滑尾段不转交画布 |
| 两层裁剪 | 放大纸面并拖到画布边缘，再将纸面拖回中央观察边缘 | 所有绘制限制在中央区内；纸面内容不覆盖工具栏和状态栏；故意延伸到页外的网格线在白纸边界截断，灰色区只保留纸张阴影 |
| 缩放按钮与复位 | 使用 - / +、100% / Ctrl＋1、Fit page / Ctrl＋0 | 按钮缩放保持画布中心锚点；100% 显示为 100%；Fit 恢复居中和整页显示，极小画布仍受最小缩放限制 |
| 页面旋转 | 连续点击 Rotate 90 deg 四次 | 每次顺时针 90°，角标随页面转动；90° / 270° 时尺寸变为 842×595 pt；第四次回到初始方向；每次重新适合页面 |
| 尺寸和 F12 | 在 fit 模式调整窗口；手动缩放或平移后再次调整；切换 F12 | fit 模式重新计算适合比例；手动模式保留画布中心对应的纸面位置；F12 信息不会遮盖纸面，布局变化后画面仍正确 |
| DPI 与跨屏 | 分别在 100%、150%、200% DPI 下操作，并跨不同 DPI 屏幕移动 | 图形与鼠标坐标匹配；纸面形状不变形；缩放锚点稳定；F12 的像素比例和物理尺寸随 DPI 更新 |
| 窗口生命周期 | 最小化、恢复、最大化、还原、失焦再回来，最后关闭 | 无残影、黑屏、持续拖动或崩溃；恢复后仍可操作；正常关闭 |

### 定位标记坐标核对

红圆点中心在 PDF 用户空间始终为 `(56, 836)`。将鼠标移到其中心附近，状态栏的 PDF 坐标应接近该值；对应 Paper 坐标如下。这里只检查几何映射，尚未加载真实 PDF。

| 顺时针旋转 | 红圆点中心的 Paper 坐标（pt） |
| --- | --- |
| 0° | (36, 36) |
| 90° | (806, 36) |
| 180° | (559, 806) |
| 270° | (36, 559) |

旋转会改变纸面坐标；缩放和平移只改变显示位置。验收时可记录通过的项目、DPI 以及未通过项目的复现步骤，再更新 PLAN.md 的状态。

# 正式保存手动验收

日期：2026-11-10，对应 PLAN 步骤 8。保存流程已接入；所有窗口、外观、真实输入和跨阅读器项目仍待用户手动验收。

## 已实现

- 菜单和 Ctrl+S 保存当前路径；草稿首次保存选择路径。Ctrl+Shift+S 另存为，成功后后续保存跟随新路径。
- 手动保存前收尾活动笔迹，捕获当前修订和共享不可变笔迹快照；PDF worker 串行处理，保存期间允许继续书写、撤销和重做。
- 每次从会话初始 PDF 生成副本，加入当前仍存在的会话笔迹。保存后保留底图、叠加层及历史，不重新打开文件；正常重开才建立新的历史。
- 标准 Ink、压感 AP 和 CBOR＋Zstd 编辑附件沿用既有格式，支持跨页笔迹。草稿方格写入普通 PDF 页面内容。
- 文件操作使用标准库：同目录 `create_new` 暂存、`write_all`、`sync_all`、回读校验、提交前变更检查及 `fs::rename`；不使用硬链接或直接调用 Windows 替换 API。
- 保存失败保留当前笔迹、修订、历史及原目标路径，显示重试 / 另存为提示。关闭、打开或退出的确认支持保存和另存为；成功且没有更新修订后才执行原操作。

## 操作与预期

由用户运行 `cargo run --offline --locked`，使用测试副本。

| 操作 | 预期结果 |
| --- | --- |
| 在草稿上写两笔，Ctrl+S，选择中文路径 | 保存包含方格背景和两笔笔迹的 PDF，标题改为文件名，未保存提示消失 |
| 用菜单保存，再 Ctrl+S；关闭并重开 | 内容和笔数保持一致，笔迹不重复；重开后旧笔迹属于底图，本次撤销历史为空 |
| 在有原有批注、链接、书签和附件的多页 PDF 各页写字后保存 | 各页位置、颜色、粗细正确，原页面内容、批注、链接、书签和其他附件保留 |
| 保存后继续写字，撤销新增笔迹，再撤销本次已保存的笔迹，重新保存并重开 | 新笔迹和已保存的会话笔迹均可撤销；重开只包含最后一次保存时仍存在的笔迹 |
| 写字后 Ctrl+Shift+S，选择另一路径，再继续写并 Ctrl+S | 原路径保持另存为之前的内容，后续保存更新新路径；标题和未保存状态正确 |
| 保存期间继续书写、撤销或重做 | 保存完成只标记捕获的修订；后续编辑保持未保存，不丢失内容和历史 |
| 草稿首次保存或另存为时取消文件选择 | 文档、未保存内容和撤销重做保持；不会产生目标 PDF |
| 有未保存内容时关闭 / 打开其他文档 / 退出，选择保存；另一次取消路径选择或制造保存失败 | 保存成功后才继续原操作；取消或失败停留原文档，确认框保留，可重试、另存为或取消操作 |
| 保存进行中请求退出；另一次在退出前取消等待 | 等待保存完成且当前内容已保存后退出；取消等待保留窗口，已授权保存继续执行 |
| 打开后用其他程序修改或删除源文件，再 Ctrl+S | 提示外部修改冲突，不覆盖外部内容；另存为新路径可以保留本会话内容 |
| 将目标设为只读或用其他程序禁止共享访问，再保存 | 显示具体文件错误，原文件保留，未保存状态不清除；解除占用后可重试 |
| 在 Edge、Acrobat 中打开并查看打印预览，再回本应用重开 | 笔迹位置、颜色和变宽外观一致；本应用能核验编辑附件。阅读器版本和结果需分别记录 |

## 验证边界

无窗口测试检查跨页和同页多笔序列化、重复保存、撤销后保存、重开扩展附件、失效私有元数据回退、草稿几何、修订检查点、迟到 / 失败响应、退出等待，以及真实文件的新建 / 替换、校验失败、外部修改、删除、只读及占用。测试不创建窗口，不运行原生对话框，不验收视觉外观。

变更检测使用会话内标准库内容摘要，提交前复核目标；它不提供多个程序同时替换同一路径时的原子比较并交换。`sync_all` 同步暂存文件，不把断电后的目录项持久化作为本轮已验证保证。

应用编辑附件解码 / 编码仍限制为 8 MiB，PDF 限制为 256 MiB；超限保存报错并保留当前编辑。加密、签名或不允许修改的 PDF 拒绝保存。步骤 9 已接入定时自动保存、草稿 PDF 副本恢复和设置持久化，替代恢复日志。自动保存只捕获已完成笔迹，不结束活动笔画；恢复以最后成功提交的 PDF 为边界，不承诺最多丢失 5–15 秒。周期、按钮、最小化、冲突及故障中断步骤见 [自动保存验收](autosave-validation.zh-CN.md)，均待用户手动执行。

P2 的代码流程已接入，完成验收仍需逐项记录上表结果；编译、静态检查及结构测试通过不等于窗口或跨阅读器验收通过。

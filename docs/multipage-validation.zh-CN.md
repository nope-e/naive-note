## 运行与样本

由用户运行：

```powershell
cargo run --offline --locked -- 'D:\documents\多页示例.pdf'
```

准备包含不同尺寸、横竖版、90/180/270 度旋转、偏移 CropBox、非 1 UserUnit、文字与扫描内容、已有批注的多页 PDF。最好每页有明显页码，便于检查串页。另准备一个不同内容的 PDF 用于切换。

| 项目 | 手动操作 | 预期结果 |
| --- | --- | --- |
| 连续阅读 | 打开多页 PDF，滚轮向下浏览，再向上返回 | 页面纵向居中排列，间距一致，底栏和工具栏页码按画布中心附近页面更新；每页内容与页号相符 |
| 滚动条定位（新增，待验收） | 拖动右侧滑块到顶部、中间和底部，再点击轨道；放大后拖动底部滑块到两端 | 纵向位置与页码同步，首末页仍可见；横向可到达文档左右边缘，滑块尺寸反映可见比例；无需滚动的方向隐藏滚动条 |
| 滚动条输入归属（新增，待验收） | 抓住滑块偏离中心的位置拖动，再拖出轨道后松开；随后在纸面拖动、缩放、切页、旋转和调整窗口 | 抓取时不跳动、不同时触发画布拖动，松开后停止；滚动条跟随视图更新；固定预留边带，滑块显示或隐藏不改变缩放锚点 |
| 混合几何 | 浏览不同尺寸、旋转、CropBox 和 UserUnit 的页面；按 F12 | 各页比例、裁剪和方向正确，不重复应用原始旋转；F12 显示当前页几何 |
| 页码定位 | 点击 Page 数字，输入中间页并回车；试首末页和超界值 | 定位目标页，输入限制在有效页号范围；适合模式重新适合目标页，手动倍率保持原值并定位页顶 |
| 翻页快捷键 | 点击画布后按 PageUp/PageDown、Home/End，或点击 Prev/Next | 前后页、首页、末页定位正确；首末页按钮正确禁用；输入页码期间 Home/End 用于文本编辑 |
| 适合与缩放 | 在中间页使用 Fit page/Ctrl+0、Fit width/Ctrl+2、100%/Ctrl+1、加减和 Ctrl+滚轮 | 当前页适合画布或宽度；100% 保持画布中心锚点；鼠标缩放锚点不跳动，倍率范围 10%—800% |
| 跨页高清 | 同时露出相邻两页，放大并静置，再拖动和返回 | 两页分别补清晰，位置稳定；相同分块坐标不会显示另一页内容，块间无缝隙或重影 |
| 页面坐标 | 将鼠标依次放到不同页面及页间空隙 | 底栏显示鼠标所在页号及该页局部 Paper/PDF 坐标；空隙显示纸面外；有效 CropBox 边角坐标正确 |
| 整篇视图旋转 | 在中间页连续点击 Rotate 90 deg 四次 | 所有页面同步增加视图旋转并重排，当前页保持选中；四次后恢复原方向，源 PDF 不变 |
| 快速跳转与切换 | 快速滚动、首末页跳转、缩放，然后立即打开另一 PDF 或 Ctrl+W | 最终内容与目标页相符，旧请求不覆盖新文档、不重新打开关闭页面；输入保持响应 |
| 打开失败 | 正常文档显示后，尝试打开损坏文件，再继续阅读旧文档 | 保留原文档、页码和视图，显示错误；旧文档其他页仍可加载和补高清 |
| 工具栏输入归属 | 鼠标在工具栏和页码框上滚轮/拖动；再在画布滚轮/拖动 | 工具栏操作不产生画布平移；画布手势正常；不会因页码文字变化造成画布高度抖动 |
| 窗口与 DPI | 调整窗口、F12 开关、最小化恢复，在 100/150/200% DPI 间移动 | 适合模式随窗口调整；手动模式保留中心纸面位置；裁剪正确并按新 DPI 补清晰 |
| 缓存和静置 | 浏览大量页面后返回旧页；关闭 F12 并静置，观察任务管理器 | 已缓存页可复用，淘汰页重新加载；补图完成后恢复按需重绘；内存不随已浏览页数无限增加，具体资源占用仍需实测 |

## 边界与无窗口证据

只对可见页安排补图；尚未加载时显示白纸，已有底图保持可见。整页底图最高 72 DPI、最长边 1024 px，CPU 底图 LRU 64 MiB；高清块 512 px、采样重叠 2 px、CPU LRU 128 MiB；Skia GPU 缓存 128 MiB。所有可见页共用最多 96 个高清块，优先当前页，其余内容保留底图。引擎最多保留 4 页显示列表，但单个列表大小没有字节预算。以上均不代表进程总内存上限。

需求稳定 80 ms 后启动补图；后台每个页面或分块完成即可返回。MuPDF 单次调用不能中途抢占，复杂页面和首次读取所有页几何可能耗时。实际流畅度、清晰度和内存表现以用户实测为准。

本次无窗口检查：`cargo clippy --offline --locked --all-targets -- -D warnings` 通过；`cargo test --offline --locked` 52 项全部通过，覆盖混合页面几何、连续布局、跨页坐标和导航、缩放锚点、逐页返回与关闭取消、跨页缓存隔离、底图预算及旧结果过滤。测试只检查数学、状态、PDF 结构和 CPU 缓冲区布局，不能证明视觉或窗口行为。
